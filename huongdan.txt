1) MOI TRUONG TRIEN KHAI (VPS tieu bieu)
--------------------------------------------------------------------------------
- Thu muc: /root/telegram-bot-dashboard
- Service systemd: bot  (Gunicorn app:app, thuong -w 1, port 127.0.0.1:5000)
- Nginx: proxy_pass toi Gunicorn; co the phuc vu /static/uploads/ truc tiep
- Cap nhat nhanh:
    cd /root/telegram-bot-dashboard && git pull origin main && \
    source venv/bin/activate && pip install -r requirements.txt && deactivate && \
    sudo systemctl restart bot
- Kiem tra:
    curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:5000/healthz
    (mong doi: 200, body OK)
